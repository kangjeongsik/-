# 사주·타로 키오스크 V13

## V13 핵심 변경
- V12의 근사 월주 계산을 제거하고 `lunar-typescript 1.8.6`의 EightChar 계산 사용
- 년주·월주·일주·시주, 오행 8글자 분포, 일간, 십성(지지는 본기 기준) 출력
- OpenAI 기본 모델을 `gpt-5.6-luna`로 변경 (환경변수 OPENAI_MODEL로 변경 가능)
- 기존 V12 관리자/QR/Mock 결제/자동정리 기능 유지

## 설치
1. 압축을 새 폴더에 풉니다. V12 폴더를 덮어쓰지 않는 것을 권장합니다.
2. PowerShell에서 이 폴더로 이동합니다.
3. `npm install`
4. 서버: `npm run server`
5. 새 PowerShell에서 화면: `npm run dev`
6. 브라우저에서 `http://localhost:5173`
7. 상태 확인: `http://localhost:3001/api/health` → version 13, ai true

## 계산 기준/주의
- 입력은 양력 생년월일과 출생 시각입니다.
- 절기 기반 팔자 계산을 지원하는 오픈소스 역법 라이브러리를 사용합니다.
- 출생지 경도에 따른 진태양시 보정은 아직 적용하지 않습니다.
- 자시(23시 전후) 일주 처리 등은 명리 학파별 기준 차이가 있으므로 실제 상용 배포 전에 경계시각 사례를 별도 검증하십시오.
- 십성의 지지 표시는 지장간 전체가 아니라 본기(주기운) 기준입니다.
