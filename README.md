# 사주·타로 키오스크 V12 — 자동운영/복구판

## V12 추가
- 관리자 PIN 변경 UI
- 백업 JSON 복원
- 결과 보관기간 설정
- 오래된 고객 결과 자동 삭제
- 관리자에서 즉시 정리 실행
- Windows 부팅 자동실행 설치/해제 BAT
- 서버 watchdog 예제
- V11 매장명/가격/초기화/결제설정/백업 유지

## 첫 설치
1. Node.js 설치
2. 압축 해제
3. 폴더에서 `npm install`
4. `start-kiosk-edge.bat`으로 테스트

## Windows 부팅 자동실행
`install-autostart.bat` 더블클릭.
해제는 `remove-autostart.bat`.

자동실행 등록 전에 반드시 일반 실행이 정상인지 먼저 테스트하세요.

## 관리자 PIN
초기값: 1234
관리자 → 데이터 관리 → 관리자 PIN 변경에서 숫자 4~8자리로 변경 가능합니다.
단, Windows 환경변수 ADMIN_PIN을 직접 지정했다면 보안을 위해 UI 변경을 막습니다.

## 개인정보 결과 자동삭제
기본 보관기간 30일.
관리자에서 일수를 바꿀 수 있습니다.
서버 시작 후 및 약 6시간 간격으로 오래된 결과를 정리합니다.

## 백업/복원
관리자에서 전체 백업 JSON을 다운로드할 수 있습니다.
복원 기능은 해당 JSON을 다시 선택하면 settings/sales/results를 복원합니다.

## 중요
- 현재 결제는 mock adapter이며 실제 결제가 아닙니다.
- 정밀 만세력은 검증 전 프로토타입입니다.
- Windows 자동실행은 PC 환경/보안설정에 따라 추가 권한이나 경로 조정이 필요할 수 있습니다.
- 실제 매장 배포 전 개인정보 처리방침과 데이터 최소수집 정책을 정하세요.
